Behind the model

Engineering better decisions through systematic iteration.

PneumoVision is an end-to-end deep learning project focused on binary chest X-ray classification, careful evaluation, and practical inference delivery.

01

Problem statement

Chest X-ray interpretation is a specialized task. This project investigates whether a purpose-built convolutional neural network can learn visual patterns that separate NORMAL from PNEUMONIA images in the project dataset.

02

Project objective

Build a reproducible PyTorch workflow, improve class-level performance through measured experimentation, and expose the final model through a reliable FastAPI inference service.

Model internals

Custom CNN Architecture

A custom PyTorch convolutional neural network designed for binary chest X-ray classification. Its forward pass returns two raw logits—one for each class—with no Softmax layer.

Detailed architecture derived from the implemented Net class in xray/ml/model/arch.py.

MODEL // NET

Architecture Summary

Input
3 × 224 × 224
Convolution Blocks
9
Pooling
3 MaxPool layers + AvgPool
Activations

Normalization

Output
2 raw logits
Classes
NORMAL / PNEUMONIA

The RGB input is resized and center-cropped to 224 × 224 before normalization. The network then applies nine convolutional blocks, each using ReLU activation and BatchNorm2d. Three MaxPool2d layers progressively reduce spatial dimensions, while 1×1 convolutions in blocks 3, 5, and 7 transform channel depth efficiently.

Later 3×3 blocks extract deeper features. An AvgPool2d layer performs global average pooling over the final 4×4 feature maps before the output convolution produces two raw class logits for NORMAL and PNEUMONIA.
